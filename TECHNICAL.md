# Технический паспорт

## Зафиксированное окружение

| Компонент | Версия |
|---|---:|
| Node.js | 24.19.0 |
| pnpm | 11.25.0 |
| Three.js | 0.181.2 |
| GSAP | 3.15.0 |
| Vite | 7.3.7 |
| Playwright | 1.64.1 |
| Chrome for Testing | 156.0.8078.4 |

Исходные диапазоны зависимостей указаны в `package.json`, точные версии — в
`pnpm-lock.yaml`. Production-команда: `pnpm run build`; выходной каталог:
`dist`. Экспорт GLB выполняется командой `pnpm run export:model`.

## Состав результата

- приложение Three.js с четырьмя режимами исследования;
- `exports/nasledie-v-kode-tower.glb` — переносимая модель glTF 2.0;
- `exports/nasledie-v-kode-tower.manifest.json` — проверка структуры экспорта;
- `renders/*.png` — четыре конкурсных кадра 1600×1000 и три мобильных кадра;
- Playwright-проверки пользовательских сценариев, WebGL и шести размеров экрана.

Экспорт использует стандартные PBR-материалы glTF. Свет, туман, интерфейс и
GSAP-анимации относятся к веб-приложению и не входят в GLB.
