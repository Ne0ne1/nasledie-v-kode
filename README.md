# Наследие в коде

Интерактивный музейный 3D-экспонат для конкурса «Здесь моя Родина».
Проект показывает стилизованную программную модель вайнахской башни: её можно
осматривать, разбирать на логические части, собирать по этапам и изучать в
рентген-режиме.

Репозиторий: [Ne0ne1/nasledie-v-kode](https://github.com/Ne0ne1/nasledie-v-kode).

## Запуск

Рекомендуется Node.js 24 LTS (проверено на 24.19.0) и pnpm 11.

```bash
pnpm install
pnpm run dev
```

Production-сборка и локальный просмотр:

```bash
pnpm run build
pnpm run preview
```

Тесты (первый запуск требует `pnpm exec playwright install chromium`):

```bash
pnpm test
```

Экспорт переносимой 3D-модели и создание конкурсных PNG-кадров:

```bash
pnpm run export:model
pnpm run build && pnpm run render:stills
```

## Управление

- Перетаскивание мышью или касание — вращение камеры.
- Колесо мыши или жест — приближение.
- Клик по части башни или предмету обстановки — название и пояснение.
- В рентгене можно выбирать предметы сквозь прозрачную оболочку.
- Логотип возвращает на главный экран.
- Панель слева — исследование, разбор, этапы и рентген.
- «Оживить архитектуру» — короткая кинематографическая сборка.
- `Esc` — закрыть карточку, информацию или прервать анимацию.

## Технологии

Vite, JavaScript, Three.js, OrbitControls, GSAP, CSS и Playwright. Геометрия,
ландшафт и каменная кладка создаются процедурно, без готовых 3D-моделей и
текстур. Повторяющаяся кладка использует `InstancedMesh`; качество рендера
автоматически снижается при низкой частоте кадров.

Проект подготовлен для Vercel: команда сборки `pnpm run build`, каталог `dist`.
Историческая оговорка приведена в [ANNOTATION.md](./ANNOTATION.md), источники —
в [SOURCES.md](./SOURCES.md), сценарий защиты — в [DEFENSE.md](./DEFENSE.md).

## Проверки

Playwright запускает настоящую WebGL-сцену в Chromium. Проверяются основные
режимы, предметы, информационные панели, завершение анимации и отсутствие
перекрытий интерфейса на шести экранах от 360×780 до 1440×900, включая
горизонтальный телефон. Скриншоты проверок сохраняются в test-results/,
конкурсные PNG — в renders/.
