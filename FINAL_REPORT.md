# Итоговый отчёт по проекту «Наследие в коде»

## Результат

Создано законченное интерактивное 3D-приложение для номинации
«3D-моделирование». Оно представляет стилизованную вайнахскую башню как
цифровой музейный экспонат: модель можно осматривать, разбирать на части,
собирать по этапам и изучать в рентген-режиме.

## Что реализовано

- процедурная башня с сужающимся силуэтом, каменной кладкой, арочными
  проёмами, венцом и ступенчатым покрытием;
- горный рельеф, атмосферный туман, направленный и заполняющий свет, тени;
- управление камерой через OrbitControls и подготовленные ракурсы;
- выбор архитектурных элементов с поясняющими карточками;
- четыре режима: исследование, разбор конструкции, этапы цифровой сборки и
  рентген с регулировкой прозрачности;
- GSAP-анимации деталей, камеры и кинематографическая обратная сборка;
- адаптивное качество рендера и оптимизация кладки через `InstancedMesh`;
- музейный адаптивный интерфейс для компьютера и мобильного экрана.

## Публикация на Vercel

Проект подготовлен к публикации: [vercel.json](./vercel.json) задаёт Vite,
команду `pnpm run build` и каталог `dist`.

Самый простой способ:

1. Загрузить папку проекта в GitHub, не добавляя `node_modules` и `dist`.
2. В Vercel выбрать **Add New → Project** и импортировать репозиторий.
3. Убедиться, что Framework Preset — **Vite**, Build Command —
   `pnpm run build`, Output Directory — `dist`.
4. Нажать **Deploy**.
5. После публикации открыть выданный адрес в приватном окне и проверить кнопку
   «Исследовать башню», все четыре режима и мобильный вид.

Текущая локальная версия сохранена коммитом `3f6ff9e`. Публичная ссылка в
отчёте не заявляется, поскольку загрузку на Vercel выполняет владелец аккаунта.
